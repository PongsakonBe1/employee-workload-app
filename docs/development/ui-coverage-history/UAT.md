# Checklist ตรวจรับโดยผู้ใช้จริง

สถานะ: **ยังไม่ได้ UAT/ลงนามโดย Tech Lead หรือทีม** การทดสอบอัตโนมัติในเฟสนี้ไม่ใช้แทนการตรวจรับนี้

ขอบเขต: บันทึกงาน–ประวัติงานใน development ใช้ข้อมูลตัวอย่างจาก repo ไม่กรอกชื่อ/ข้อมูลผู้รับบริการจริง ข้อมูลเริ่มใหม่เมื่อ refresh

| กรณี | สิ่งที่ให้ทดลอง | เกณฑ์ที่ผู้ใช้ควรยืนยัน | ผลทีม |
|---|---|---|---|
| Manual | เลือกหัวข้อ วันที่/เวลา suggestion → ตรวจ → ยืนยัน → ดูประวัติ | ลำดับตรงแบบ ข้อมูลไม่หายก่อนยืนยัน อ่านรายละเอียดได้ | รอตรวจ |
| โทรศัพท์ | บันทึกโดยเว้นผู้รับบริการและรายละเอียด แล้วเติมทีละช่อง | focus/ข้อความช่วยตรงช่อง ไม่ต้องเลื่อนหาเอง | รอตรวจ |
| งานมอบหมาย | Quick Log หน้าสอง เว้นรายละเอียดก่อน แล้วเติมและบันทึก | มีรายการนี้ครบ ข้อความแสดงหัวข้อถูกต้องในประวัติ | รอตรวจ |
| Combo | ไม่เลือกเลย → เลือกบางรายการ → ยืนยัน → ดูประวัติ | เริ่มว่าง จำนวนและรายการตรงที่ทำจริง | รอตรวจ |
| Failure | เปิดตัวเลือกตรวจแบบ จำลองบันทึกไม่สำเร็จ แล้ว retry | ร่างอยู่ครบ ไม่ขึ้นสำเร็จหลอก ไม่เกิดรายการซ้ำ | รอตรวจ |
| ยืม/คืน | ใช้รหัสสังเคราะห์ 13 หลัก ยืม/คืน → ประวัติ → Undo | รหัสไม่ถูกแปลงเป็นเลข สถานะสัมพันธ์กัน | รอตรวจ |
| วัน/รายละเอียด | ประวัติแบบปฏิทิน เลือกวัน → งาน → กลับ | ไม่เด้งกลับ list และวันหยุดไม่เพิ่มจำนวนงาน | รอตรวจ |
| ค้นหา/วันที่ | ค้นหาผู้รับบริการ เปลี่ยนช่วงวันที่ ลองช่วงผิดและยกเลิก | ผลกรองตรง คำเตือนชัด ยกเลิกไม่เปลี่ยนข้อมูล | รอตรวจ |
| สิทธิ์จำลอง | Staff เทียบ Admin และบัญชีตัวอย่าง A/B | แยกรายคนด้วย ID ไม่สับสนจากชื่อ เห็นเหตุผลที่แก้ไม่ได้ | รอตรวจ |
| แก้/ลบ/Undo | แก้ข้อความ เลือกหลายรายการ ลบหลังยืนยันแล้ว Undo | ไม่มี partial change คืนรายการ/สถานะได้ตรงกัน | รอตรวจ |
| CSV | กรองเหลือบางรายการและดาวน์โหลด | จำนวนและ field ตรงผลกรอง ข้อความไทยถูกต้อง | รอตรวจ |
| Mobile | iPhone Safari และ Android Chrome จริง | form ไม่ล้น/ไม่ zoom ขณะพิมพ์ ปุ่มแตะสะดวก details อ่านได้ | รอตรวจ |
| Appearance | Light/Dark และลดการเคลื่อนไหว/ความโปร่งใส | สถานะยังอ่านได้ ไม่มี animation ที่รบกวนการลงงาน | รอตรวจ |
