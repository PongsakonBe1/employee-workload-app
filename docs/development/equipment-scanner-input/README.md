# Smart Quick Log สำหรับเครื่องสแกน

หูฟัง ปลั๊กไฟ และ USB ใช้ช่องรหัสนักศึกษาแบบเดียวกัน หลังเลือกอุปกรณ์พร้อมยืม ระบบโฟกัสช่องทันที รับเฉพาะเลข `0–9` ครบ 13 หลัก เก็บเลขศูนย์นำหน้า และรองรับ Enter ท้ายรหัสจากเครื่องสแกน หากสแกนออกมาเป็นตัวอักษร ระบบแจ้งให้เปลี่ยนแป้นพิมพ์เป็น EN แล้วสแกนใหม่

คืนอุปกรณ์ด้วยผู้ยืมจากบันทึกเดิมโดยไม่มีช่องให้สแกนซ้ำ ข้อมูลผู้ยืมเก่าที่เก็บเป็นข้อความยังนำมาคืนได้ ปุ่มยืนยันถูกล็อกระหว่างส่งและกลับมาให้ตรวจได้หากบันทึกไม่สำเร็จ ถ้า worklog บันทึกแล้วแต่สถานะซิงก์ไม่สำเร็จ ระบบแจ้งแยกจากผลการบันทึกเพื่อให้ผู้ใช้ไม่ส่งรายการเดิมซ้ำ โครงสร้างเอกสารและ Firestore Rules ใช้ชุดเดิม

ตรวจบน production-mode build ที่ชี้ Firebase Emulator ในเครื่องแล้ว อุปกรณ์ทั้งสามเปิดช่องตัวเลขและโฟกัสได้ เลขไทย ตัวอักษร เลข 12 และ 14 หลักกด Enter แล้วไม่มีเอกสารถูกสร้าง ยืมหูฟังหนึ่งครั้งด้วยสแกนจำลองรวมกด Enter ซ้ำ จากนั้น reload แล้วคืนด้วยรหัสเดิม ตรวจพบ worklog ยืมและคืนอย่างละหนึ่งรายการและสถานะพร้อมยืมหลัง reload [ผล Browser QA](../../../output/playwright/equipment-scanner-input/report.json)

Unit tests เฉพาะตัวตรวจรหัสและเส้นทางอุปกรณ์ผ่าน 12 รายการ พร้อม targeted lint และ build ผ่าน

ผู้ใช้ยืนยันว่าทดลองด้วยเครื่องสแกนจริงกับหูฟังตัวอย่าง ICIT01 บนคอมที่เปิด Firebase Emulator แล้ว ตรวจกลับพบ worklog ยืมและคืนอย่างละหนึ่งรายการ รหัสเป็นเลข 0–9 ครบ 13 หลักและตรงกัน สถานะกลับเป็นพร้อมยืม [ผลตรวจรับเครื่องสแกน](../../../output/playwright/equipment-scanner-input/physical-scanner-uat.json)
