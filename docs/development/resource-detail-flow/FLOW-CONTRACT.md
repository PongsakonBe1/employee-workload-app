# กดอะไรแล้วต้องเจออะไร

สถานะ automated acceptance ผ่านด้วยข้อมูลสังเคราะห์ ยังรอผู้ใช้ตรวจรับจริง

| จุดเริ่มและการคลิก | PC >900px | พื้นที่ ≤900px | สิ่งที่ต้องไม่เกิด |
|---|---|---|---|
| เลือกห้อง/อุปกรณ์ในทรัพยากร | ไฮไลต์แถวและเปลี่ยนแผงรายละเอียด | เปิด sheet รายละเอียด | ไม่สร้างบันทึก ไม่เปิดฟอร์มทำรายการทันที |
| เลือกเปิด/ปิด/ยืม/คืนจากรายละเอียด | เปิดหน้าต่างทำรายการ | เปลี่ยนจากรายละเอียดเป็นหน้าต่างทำรายการ | ไม่มี modal ค้างซ้อน |
| ยกเลิกทำรายการ | กลับแผงรายละเอียด สถานะเดิม | กลับ sheet รายละเอียด สถานะเดิม | ไม่เพิ่ม worklog |
| ยืนยันบันทึก | แผงรายละเอียดและรายการอัปเดต | กลับ sheet รายละเอียดที่อัปเดต | ไม่สลับ resource ID |
| ดูประวัติจากทรัพยากร/ทะเบียน | เปิดประวัติของ ID ที่เลือก | เปิดประวัติของ ID ที่เลือก | ไม่ดึงรายการชื่อคล้าย/ชนิดอื่น |
| เปลี่ยนช่วงวันที่ผิด | แสดงเหตุผล คงช่วงและแถวเดิม | เหมือน PC | ไม่ export ตามร่างที่ยังไม่ผ่าน |
| คืนค่าช่วงเดิม | คืนค่าร่างเป็นช่วงที่ใช้อยู่ | เหมือน PC | ไม่เปลี่ยนข้อมูลบันทึก |
| ดาวน์โหลด CSV ประวัติ | ได้แถวที่ตรง ID/ช่วง/สิทธิ์ที่เห็น | เหมือน PC | Staff ไม่ได้ประวัติคนอื่น |
| กลับรายละเอียดจากประวัติ | ปิดประวัติ เห็นแผงเดิม | คืน sheet รายละเอียดเดิม | ไม่เปลี่ยน selection |
| X/Escape ที่ประวัติ | ปิดกลับรายการ | ปิดกลับรายการ | ไม่เปิดหน้าต่างใหม่โดยไม่ตั้งใจ |
| ส่งออกสถานะที่หัวหน้า | เปิดตรวจไฟล์ทุกห้อง/อุปกรณ์ | เปิดตรวจไฟล์และเลื่อนตารางแนวนอนได้ | ยังไม่ดาวน์โหลดเอง |
| ยกเลิกตรวจไฟล์ | กลับรายการ | กลับรายการ | ไม่มี download/worklog ใหม่ |
| ดาวน์โหลด CSV สถานะ | ดาวน์โหลดและปิด preview | เหมือน PC | ไม่ใส่คอลัมน์รหัสผู้ยืม |
| จำลองสร้างไฟล์ไม่สำเร็จ | แสดง error และคงแถวตรวจไว้ | เหมือน PC | ไม่ล้างข้อมูลก่อน retry |
| แก้/ซ่อนอุปกรณ์จากรายละเอียดมือถือ | — | กลับ ID เดิมและดูสถานะที่แก้แล้วได้ แม้ซ่อนจาก Quick Log | ไม่แสดงอุปกรณ์ตัวอื่นแทน |

ให้ลอง Light/Dark, keyboard และอุปกรณ์จริงด้วย ข้อมูลตัวอย่างจะเริ่มใหม่เมื่อ refresh; ใช้เมนูในแอประหว่างตรวจ flow ข้ามหน้า

การรับรองครอบคลุม flow ในตารางนี้ ไม่แทนการรับรองทุกปุ่มใน 30 views ของต้นแบบหรือระบบ production
