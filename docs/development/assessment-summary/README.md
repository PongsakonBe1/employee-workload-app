## สิ่งที่เพิ่ม

### ภาพรวม

ค่าเริ่มต้นยังรายสัปดาห์และแสดงหัวข้อที่พบบ่อยตาม Review 10 เพิ่มสลับ “บ่อยที่สุด / ทุกหัวข้อ” พร้อมค้นหา กรองหมวด และรวมรายการที่เป็นศูนย์ มีทางเปิดรายการทั้งหมดในหน้าต่างแยกด้วย หัวข้อเก่านอก catalog ยังคงแสดง ไม่ทิ้งจากยอด

แสดงจำนวนตามข้อมูลที่โหลด ถ้ายังโหลดไม่ครบใช้ ≥ และ — เพื่อไม่ทำให้รายการที่ยังไม่พบดูเหมือนศูนย์ครบช่วง การดูทุกหัวข้อเป็นการกรองข้อมูลในหน่วยความจำ ไม่สั่งโหลดทั้งปีหรือทุกคนเพิ่มเอง

### สรุปประกอบแบบประเมิน

เปิดจากปุ่ม “สรุปแบบประเมิน” ได้ทั้ง Overview และ Staff Analytics

1. เลือกบุคคล รอบ 1/2/3 หรือพนักงานใหม่ และระบุช่วงวันที่
2. กดแสดงสรุป ระบบเรียงหมวด 1.1–1.8, 2.1, 3.1 ตามแบบประเมินฉบับที่ผู้ใช้ส่งมา
3. กดหัวข้อหรือหมวดเพื่อตรวจบันทึกต้นทาง กลับสรุปได้โดยรักษา keyboard focus
4. แสดงข้อความสรุปหรือคัดลอกทั้งรอบได้ Clipboard ไม่พร้อมจะมีกล่องข้อความให้เลือกคัดลอกเอง

วันสิ้นสุดใช้ตรวจป้ายปีงบ กรณีช่วงคร่อมปีงบจะแสดงหมายเหตุและนับตามช่วงวันที่ที่ระบุจริง รายงานเลือกหนึ่งบุคคลเสมอ Staff ดูเฉพาะ ID ของตน; Admin/Superadmin จำลองเลือกคนได้ เปิดใหม่ตามตัวกรองบุคคลบนหน้าหลัก โดยยังจำรอบและวันฉบับร่างใน tab

### ผังจับคู่และความครบถ้วน

ผังตั้งต้นเพื่อให้ reviewer ตรวจ แยกจากน้ำหนัก JD เดิมและใช้ร่วมกันทั้งทีมในต้นแบบ ผู้ดูแลปรับผังหัวข้อรอง → ข้อในแบบประเมินได้ หนึ่งหัวข้ออยู่ได้หนึ่งหมวด ยอดของหมวดกับรายการที่ยังไม่จับคู่รวมกลับเป็นจำนวนบันทึกเสมอ

- **0 ครั้ง** = มีหัวข้อที่จับคู่ แต่ไม่พบบันทึกในช่วงนั้น ไม่ใช่หลักฐานว่าไม่ได้ทำงาน
- **ยังไม่มีหัวข้อที่จับคู่** = ยังไม่มีโครงสร้างข้อมูลรองรับข้อนั้น ไม่สรุปเป็นศูนย์
- งานซ่อม/ติดตั้งที่ระบุหน่วยงานหรือ IT Clinic ไม่ได้คงเป็นยังไม่จับคู่ ไม่มีการเดาจากคำใกล้เคียง
- คุมสอบ DL ไม่นับซ้ำเป็นการจัดเตรียมห้องสอบ
- ยังประเมิน SLA/ระยะเวลาซ่อม/เตรียมห้องล่วงหน้าไม่ได้ เพราะไม่มีข้อมูลครบสำหรับวัด
- คะแนนผลงาน 80 และพฤติกรรม 20 เป็นส่วนที่ผู้ประเมินพิจารณา ไม่แปลงความถี่เป็นคะแนนและไม่ใช้เป็นน้ำหนัก JD
- เกิน 1,000 บันทึกต่อคน ต้องกดโหลดเพิ่มเอง ปิดการคัดลอกสรุปจนโหลดครบ หากบุคคลนั้นมีวันที่ไม่ถูกต้องจะระงับการคัดลอกให้ตรวจข้อมูลก่อน
- นับตาม stable employee ID; บันทึกเก่าที่ขาด ID ยังต้องตรวจการจับคู่เมื่อทำเฟสเชื่อมข้อมูลจริง

ไม่บันทึกชื่อ เงินเดือน ลายเซ็น หรือยอดตัวอย่างจาก PDF ลง fixtures และไม่เพิ่มภาพ PDF ที่มีข้อมูลบุคคลลง Git

### Staff Analytics

คงตารางตัวเลข เพิ่มกราฟแท่งแนวนอนแยกหมวดตามแบบประเมิน เลือกจำนวน/สัดส่วนได้ ตัวเลขจริงยังอยู่ด้านขวา เรียงตามรายชื่อทีมไม่จัดอันดับคะแนน การค้นและเลือกคนใช้กับตารางและกราฟชุดเดียวกัน

เมื่อเลือกคนเพิ่มกราฟเส้นแนวโน้ม แกนเริ่มศูนย์และมีทางเปิดค่ารายช่วง/บันทึกต้นทาง ไม่ลากเส้นไปยังอนาคตที่ยังไม่มีข้อมูล มีข้อความแยกจำนวนบันทึกจากระยะเวลา ความยาก และคุณภาพบุคลากร

ใช้ semantic colors ต่อหมวด คำอธิบายและรายการต้นทางยังใช้ได้โดยไม่พึ่งสี มี light/dark, reduced motion, forced colors และขนาดฟอร์มมือถืออย่างน้อย 16px
