# ตรวจรับ UI รอบเก็บรายละเอียด

ยังรอผู้ใช้ตรวจจริง ใช้ข้อมูลตัวอย่างเท่านั้น บันทึกอุปกรณ์ browser และข้อเสนอแนะ

| สิ่งที่ลอง | ผลที่คาดหวัง |
|---|---|
| มือถือ Light/Dark เปิดทรัพยากรและสลับเมนู | เมนูที่เลือกอ่านได้ ไม่ถูก selection lens ทับ แม้กำลังโหลด |
| เปิด/ปิดห้องจากรายการ → รายละเอียด → Quick Log แล้ว Undo | ข้อความและสีแต่ละสถานะตรงกันทุกหน้า สถานะย้อนกลับถูกต้อง |
| หน้าการใช้งานมือถือ เปิดตัวกรอง เลือกสังกัด แล้วปิด/เปิดอีกครั้ง | controls อ่านเป็นคำ ตัวกรองแสดงจำนวนที่ใช้ ค่าที่เลือกยังอยู่ |
| เปิดเพิ่มอุปกรณ์บนมือถือ เลื่อนขึ้นลง | ข้อมูลเป็นกลุ่ม เห็นปุ่มยกเลิก/เพิ่มตลอดช่วงเลื่อน body |
| เปิดข้อมูลเพิ่มเติม ใส่ลำดับ -1 ปิดข้อมูลเพิ่มเติม แล้วบันทึก | เปิดส่วนที่ผิดและ focus ช่องลำดับ เห็นเหตุผลที่ footer โดยไม่เลื่อนหา ไม่มีข้อมูลใหม่ถูกสร้าง |
| ยกเลิกฟอร์มที่แก้แล้ว | ทะเบียนเดิมไม่เปลี่ยน |
| เลือกอุปกรณ์ในทะเบียน แล้วเปลี่ยน “แสดงในบันทึกด่วน” | ความหมายต่างจากพร้อมยืมชัดเจน รายการค้างคืนยังอยู่ และ Undo คืนค่าได้ |
| อ่านรหัสอุปกรณ์ หมายเหตุ สภาพตอนคืน ในสองธีมและ zoom 200% | ข้อมูลรองยังอ่านได้ ฟอร์มไม่เกินจอและคำสั่งเข้าถึงได้ |

ผลผ่านอัตโนมัติอยู่ใน reports แต่ยังไม่ลงสถานะ human UAT ผ่านแทนผู้ใช้
