# รายการตรวจรับ — ห้องและอุปกรณ์

ยังรอผู้ใช้ตรวจจริง บันทึก browser/อุปกรณ์ ผลที่พบ และข้อเสนอแนะ โดยใช้ข้อมูลตัวอย่างเท่านั้น

| ลำดับ | สิ่งที่ลอง | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดทะเบียนด้วย Staff / เปลี่ยนเป็น Admin ในตัวเลือก Development | Staff ไม่จัดการทะเบียน; Admin เห็นเพิ่มและแก้ไข |
| 2 | เพิ่มหูฟัง ชื่อและรหัสใหม่ สภาพสมบูรณ์ | บันทึกครั้งเดียว รายการและรายละเอียดตรงกัน |
| 3 | กรอกรหัสหรือ barcode ซ้ำ | แจ้งเหตุผลและ focus ช่องรหัส ร่างยังอยู่ |
| 4 | ตั้งให้บันทึกครั้งถัดไปล้มเหลว แล้วเพิ่มอีกครั้ง | retry ได้โดยไม่สร้างรายการซ้ำ |
| 5 | ใช้เมนูไปบันทึกงาน → หูฟัง | เห็นอุปกรณ์ใหม่โดยไม่ refresh |
| 6 | ยืมจากทรัพยากร ลองว่าง/เลขไทย/12 หรือ 14 หลัก ก่อนใช้เลข 0 จำนวน 13 ตัว | แจ้งผิดและ focus ช่อง; รับเฉพาะ ASCII 13 หลัก |
| 7 | ย้ายอุปกรณ์ที่ยืมแล้วจากชั้น 3 ไป Finn Space และเปลี่ยนชื่อ | Quick Log เปลี่ยนชื่อ/สังกัด แต่รหัสผู้ยืมเดิมอยู่ |
| 8 | หยุดใช้อุปกรณ์ขณะยืม แล้วคืนใน Quick Log | ยังคืนได้ คืนเสร็จซ่อนจากรายการยืมใหม่ |
| 9 | คืนโดยเลือกยังไม่ระบุ / ชำรุด / สูญหาย | unknown ไม่เพิ่มคืนสมบูรณ์; ชำรุด/สูญหายทำให้ยืมต่อไม่ได้ |
| 10 | Undo หลังเปิดห้อง/ยืม/คืน/ย้ายสังกัด/หยุดใช้ | กลับสถานะก่อนคำสั่งล่าสุดและสถิติตรงกัน |
| 11 | การใช้งาน → สังกัดปัจจุบัน → เปิดอุปกรณ์ → ประวัติ | แสดง location ของแต่ละ event และเฉพาะ ID/ช่วงที่เลือก |
| 12 | สลับวัน สัปดาห์ เดือน ไตรมาส ปีงบประมาณ และเลือกช่วงเอง | ยอดเปลี่ยนตามช่วง; กำลังยืมตอนนี้ไม่ลดเพราะเปลี่ยนช่วงหรือบุคลากร |
| 13 | PC เลือกรายการแล้วแก้ไขจากแผงขวา; มือถือเลือกแล้วแก้จาก sheet | ไม่หลุดบริบท ฟอร์ม/ปุ่มไม่เกินจอ เลื่อนถึงบันทึกได้ |
| 14 | Dark/Light/Solid/Reduced Motion, keyboard และ zoom 200% | อ่านสถานะได้โดยไม่อาศัยสีอย่างเดียว และเข้าถึงคำสั่งได้ |

อุปกรณ์ตรวจจริงที่ยังรอ: iPhone/Safari, Android/Chrome, Windows/Chrome, Mac/Chrome หรือ Safari และเครื่องอ่านบัตรของทีม

ห้ามใช้ refresh ระหว่าง flow ที่ต้องยืนยันข้อมูลร่วม เพราะ adapter เริ่มใหม่เมื่อ refresh ให้ใช้เมนูในเว็บเชื่อมหน้า
