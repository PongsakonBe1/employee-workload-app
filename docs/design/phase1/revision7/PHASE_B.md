# Review 08 ชุดสอง — ปฏิทินและการออกแบบร่วม

วันที่ 5–6 พฤศจิกายน 2569 · branch `codex/liquid-glass-review-08` · ฐานชุดแรก `917d854`

ผู้ใช้อนุมัติให้พัฒนาชุดสองแล้ว งานนี้เป็นต้นแบบข้อมูลสังเคราะห์ในโฟลเดอร์เดิม `revision7` ใช้ server และ public preview เดิมที่อนุมัติ ไม่แก้ frontend production, Firestore, สิทธิ์ผู้ใช้, dependency หรือ deploy

## ผลที่เปลี่ยน

- แก้สีปฏิทิน Light/Dark ที่ค่าสีจากฐานเก่าทับกัน แยกพื้น/ข้อความ/เส้นของตารางเรียนสีม่วง, DL สีน้ำเงิน, สอบรายวิชาสีส้ม และสีวันหยุด ทุกชนิดมีข้อความกำกับ
- มือถือใช้หัวเรื่องและปุ่มเพิ่ม แถววันที่ และตัวเลือกวัน/สัปดาห์/เดือน/รายการ ตัวกรองห้อง ประเภท ภาคเรียน และปฏิทินเพิ่มเติมรวมใน sheet เดียว ปุ่มนำเข้า/คัดลอก/จัดรายการเดิมอยู่เมนูเครื่องมือ ไม่มีการตัดคำสั่งเดิมออก
- PC ใช้แถบควบคุมกระชับ มุมมองสัปดาห์เป็นค่าเริ่มต้น มือถือเริ่มที่วัน ผู้ใช้เลือกมุมมองอื่นได้ โดยรักษาวันที่ ห้อง ประเภท และภาคเรียน
- ปุ่มวันนี้และวงวันที่ปัจจุบันใช้วันจริงในเขตเวลา Asia/Bangkok ไม่ค้างวันที่ fixture ตรวจขอบเขตเที่ยงคืนไทยและข้ามปีแยกไว้แล้ว วันที่เริ่มต้นของตารางตัวอย่างยังคงไว้เพื่อเทียบผลตรวจได้
- เดือนบน PC แสดงชื่อ/เวลาและรายการเพิ่มเติม เดือนบนมือถือแสดงวันที่ จุดสี/จำนวนกิจกรรม และป้ายวันหยุด แตะช่องวันเพื่อเปิดรายการเต็ม ไม่บีบชื่อกิจกรรมลงในช่องแคบ
- เกิดรายการรายสัปดาห์ตามวันและช่วงที่มีผลจริงของแต่ละวิชา แต่ละ occurrence มีวันที่ชัดเจน เมื่อคลิกในเดือนจะเปิดวันที่นั้น ไม่หลุดไป occurrence แรกของเดือน
- รายละเอียด event ใช้ popover ใกล้รายการบน PC และ sheet บนมือถือ ปุ่มแก้ไขเดิมตามสิทธิ์ยังอยู่ วันหยุดไม่ยกเลิกหรือกีดกันการเพิ่มตารางโดยอัตโนมัติ
- ปฏิทินประวัติงานและ DL ใช้วันหยุดชุดเดียวกับตารางรวม และรายละเอียดประวัติรายวันแสดงวันหยุดด้วย จำนวนงานไม่นับวันหยุดเป็นรายการงาน
- ปรับ semantic colors, ภูมิหลัง, Glass layer, icon weight และไอคอนแบบมีสี/ชั้นสีร่วมทั้ง 30 หน้า เปลี่ยนไอคอนรับโทรศัพท์จากเครื่องหมายคำถามเป็นโทรศัพท์ และใช้ไอคอนประตูสำหรับการเปิด/ปิดห้อง
- สีสถานะกำลังยืมใช้สีน้ำเงินทั้งหน้ารายการและ modal ส่วนเสียหาย/รอตรวจใช้สีเตือนตามความหมายเดิม
- Glass อยู่ที่ navigation, toolbar selection และ shell ของ dialog เนื้อหาและตารางใช้พื้นอ่านชัด มี fallback สำหรับ Solid/ลดความโปร่ง/เพิ่ม contrast
- ลดการเด้งไอคอนเมื่อ hover และการสั่นกระดิ่งทุกครั้ง เพิ่ม feedback ตอนบันทึกจริงและ fade สั้นเมื่อเปลี่ยนมุมมอง/วันที่ ใช้งานต่อได้ทันที รองรับ Reduce Motion ทั้งจากระบบและตัวเลือกในต้นแบบ ไม่มี loop ตกแต่งต่อเนื่อง

## แนวทาง Apple ที่ประยุกต์

| บริบท | แนวทางอ้างอิง |
|---|---|
| ตาราง PC / มือถือ | iCloud Calendar / Calendar: แยกการนำทางช่วงเวลา มุมมอง และปฏิทินที่แสดง; มือถือเป็น layout แยก ไม่ย่อ desktop ตรง ๆ |
| ห้อง/อุปกรณ์ | Home: ไอคอนและสีช่วยแยกหมวด สถานะต้องอ่านได้ก่อนกด รายละเอียดใช้ sheet |
| รายการ/ทะเบียน | Finder: รายการกับ inspector และคำสั่งรองตามบริบท |
| กรอกงาน | Reminders/Entering data: รักษาค่าที่กรอกและ suggestion เดิม ใช้ข้อมูลผู้ยืมเดิมตอนคืน |
| กราฟ | Charting data: รักษาหน่วยและข้อมูลเดิม ปรับสี/ความอ่านง่ายร่วม สูตร Staff Analytics อยู่ชุดถัดไป |

ใช้หลักจาก [Color](https://developer.apple.com/design/human-interface-guidelines/color), [Icons](https://developer.apple.com/design/human-interface-guidelines/icons), [Layout](https://developer.apple.com/design/human-interface-guidelines/layout), [Materials](https://developer.apple.com/design/human-interface-guidelines/materials), [Motion](https://developer.apple.com/design/human-interface-guidelines/motion), [Entering data](https://developer.apple.com/design/human-interface-guidelines/entering-data), [Charting data](https://developer.apple.com/design/human-interface-guidelines/charting-data) และ [Right to left](https://developer.apple.com/design/human-interface-guidelines/right-to-left)

ค่าสี ขนาด และระยะเวลาการเคลื่อนไหวเป็นค่าของโครงการ ไม่อ้างว่าเป็นค่าบังคับจาก Apple ใช้ SVG ที่สร้างในโครงการ ไม่มีการแจก SF Symbols หรือ SF Pro สำหรับเว็บข้ามแพลตฟอร์ม ดูข้อจำกัดภาพระบบใน [Xcode and Apple SDKs Agreement ข้อ 2.10](https://www.apple.com/legal/sla/docs/xcode.pdf) ภาษาไทย/อังกฤษยังเป็น LTR และไม่กลับลำดับวันที่ เวลา หรือรหัสนักศึกษา

## วันหยุดและแหล่งข้อมูล

- `data/th-holidays.json`: snapshot จาก Google Calendar ประเทศไทยแบบสาธารณะ ดึงในรอบนี้ 322 รายการ ปี 2021–2031 แยกวันหยุดนักขัตฤกษ์ 257 รายการ และวันสำคัญ 65 รายการ ตามชนิดใน DESCRIPTION ของต้นทาง
- ค่าเริ่มต้นเปิดวันหยุดนักขัตฤกษ์ และปิดวันสำคัญ ทั้งสองปฏิทินใช้ตัวเลือกเดียวกัน ดูวันที่อัปเดตได้ในตัวกรอง
- วันที่เป็น date-only; DTEND เป็นวันสิ้นสุดแบบไม่นับวันนั้น ไม่แปลงเป็นเวลาท้องถิ่นจนเลื่อนวัน ไม่มีการอนุมานวันหยุดมหาวิทยาลัยจากปฏิทินประเทศ
- ถ้าโหลด snapshot ไม่สำเร็จ จะแจ้งสถานะและโหลดใหม่ได้ ตารางเรียน/สอบยังใช้ต่อได้ หากเลือกปีนอกช่วงข้อมูลจะระบุว่าไม่มีข้อมูลปีนั้น
- เป็น snapshot ไม่ใช่การ sync บัญชี Google ส่วนตัว และไม่มี OAuth/credential การ refresh ใช้ `node docs/design/phase1/revision7/refresh-holidays.cjs` ซึ่งเรียกเฉพาะ URL สาธารณะที่กำหนดตายตัว

5. รอ Tech Lead ตรวจรับชุดนี้ก่อนเริ่มชุด Analytics/JD ไม่ได้เปลี่ยนสูตรตัวชี้วัด เพิ่มการนำเข้า PDF จริง หรือเขียนข้อมูล production ในชุดนี้
